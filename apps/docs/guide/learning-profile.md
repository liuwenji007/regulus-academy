# 学习画像

Regulus 用画像裁剪建课与讲解：**不重复你会的，只练你弱的**。入口：设置 → 学习画像。

机制背景见 [教学模式](./teaching-model.md)；本文只说明你能看到、能改什么。

## 两层画像

| 层级 | 存什么 | 上限 | 谁用 |
|------|--------|------|------|
| **全局** | 背景、目标、偏好；可汇总为 `profile_summary` | 摘要合计约 ≤500 字 | 建课裁剪、各课讲解注入 |
| **按课（domainProfiles）** | 该课掌握摘要 | 每课约 ≤200 字 | **该课** Coach 讲解时优先参考 |

按课摘要在节点点亮后异步写入；设置页可浏览，完成节点越多越贴你。

## 生命周期

| 时机 | 说明 |
|------|------|
| 冷启动 | 首次进入可选 2～3 题，可跳过 |
| 节末合并 | 节点点亮后异步把本节对话并入全局 / 按课摘要 |
| 设置页编辑 | 结构化填写背景、目标、偏好；也可用对话补充 |

## 设置页能改什么

- **背景** — 岗位、已有技术栈（影响跳过什么）
- **目标** — 想学到哪一层、用在什么场景
- **偏好** — 节奏、讲解风格等（若有）
- **按课摘要列表** — 只读浏览各课掌握摘要，可点进对应课程

下一节讲解会自动注入更新后的画像。
