# 课程体检与优化

在课程详情页可对整门课做一次**质检**，并按建议**补全节点内容**，过程中**保留你已有的学习进度**。

## 和纵深扩展的区别

| | 课程体检 / 优化 | 纵深扩展 |
|--|-----------------|----------|
| 改什么 | **现有**节点 YAML（结构、完整性、教考对齐等） | 完成度 ≥80% 后**追加**进阶节点 |
| 进度 | 保留 | 保留已有进度 |
| 入口 | 「课程体检」 | 「解锁进阶路径」 |

## 怎么用

1. 打开课程详情 → **课程体检**
2. 等待异步报告：结构 / 节点完整性 / 教考对齐 / 前置依赖，以及可选 AI 总评
3. 勾选可自动修复项 → 预览补丁 → 确认写入

## 分数怎么读

综合分表示**可否正常开练**的健康度，不是「打磨已完成、零优化空间」：

| 级别 | 含义 | 是否扣分 |
|------|------|----------|
| 严重 | 课不可用或路径断裂（如无效前置） | −15 |
| 待改进 | 大概率伤害讲解/练习质量 | −5 |
| 提示 | 可选打磨（如缺 `grading_hints`） | **不计分** |

因此「100 分 + 若干提示」表示可以开练，仍可按提示继续打磨。`must_teach` 体检只要求每个教学节拍有**至少一条非空**必讲要点；一条写清楚即可，不强制凑到两条。

练习侧 `exercise_ideas` 仍按核心概念数量要求题池条数（题要多样）；讲解侧不按条数凑数——门槛不对称是有意的。

## 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `REGULUS_COURSE_AUDIT_LLM` | 开 | `0` 则仅规则体检、无 LLM 整树评语 |
| `REGULUS_COURSE_OPTIMIZE_LLM` | 开 | `0` 关闭 LLM 优化 |

完整列表见 [环境变量](../reference/env.md)。
