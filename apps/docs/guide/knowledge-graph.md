# 知识图谱

入口：点侧栏的「知识图谱」。

当你学了多门课，需要回答「我在哪、还剩多少、课与课之间有什么关系」时，打开知识图谱。它是**辅助视图**，不挡主学习路径（输入领域 → 选节点 → 对话学习）。

![知识图谱 · 宣纸](/screenshots/graph-paper.png)

## 图谱 / 目录双视图

顶栏可切换两种读法：

| 视图 | 适合 | 操作 |
|------|------|------|
| **图谱** | 看全局关系、缩放探索、感受进度光效 | 拖动画布、滚轮缩放、单击定位、双击领域进课程 |
| **目录** | 按清单浏览，点开即练 | 领域卡片 + 模块列表 + 节点芯片 |

目录视图顶栏固定宣纸色；图谱视图可切换主题。

## 宣纸 / 星空双主题

顶栏主题按钮显示的是**将要切换到的主题**。

| 主题 | 特点 | 星座排布 |
|------|------|----------|
| **宣纸**（默认） | 水墨晕染、墨色印章标记进度，偏工具感 | **chart**：盖天式同心圈层 + 分野扇区 |
| **星空** | 星云光晕、节点星光，偏仪式感 | **spiral**：银河旋臂；预设领域各占一臂 |

![知识图谱 · 星空](/screenshots/graph-sky.png)

主题偏好保存在浏览器本地，换设备需重新选择。

## 领域与星座

每门课可归入一个**领域**（如「编程语言」「AI 与数据」，也可自定义，合计最多 8 个）。建课时模型会自动归类，也可在课程页 / 我的课程里改；重新生成课程会保留你已设的领域。

图谱里同领域的课会聚在一起：星空按旋臂、宣纸按扇区；未分类落在固定槽位。我的课程页也可按领域筛选。

## 缩放与 LOD

图谱视图随滚轮缩放自动切换细节层级：

| 层级 | 可见内容 |
|------|----------|
| **全景 / 银河** | 多门课时先看领域与星座轮廓 |
| **星座** | 单课结构（模块与主题）铺成星座形 |
| **节点** | 全部知识点 + 课内推荐路径连线 |

父子课程之间有**父 → 子**有向边，与主题族的弱关联边不同。

## 进度怎么读

- **进行中**：节点橙色脉冲
- **已完成**：金色呼吸光晕（星空）或墨色印章（宣纸）
- **全领域学完**：星空下变为 starlight 星光

单击节点或目录里的节点芯片，可直接开始该节点的教练对话。

## 与课程详情页的区别

| | 知识图谱 | 课程详情页 |
|---|-------------------|----------------------|
| 范围 | 多门课、多领域 | 单门课 |
| 主要用途 | 全局感知、跨课关系 | 按节点学习、导出、纵深扩展 |
| 子课跳转 | 图谱有向边 | 根课页锚点后有「深入学习」条 |

父子课程关联的建课逻辑见 [教练流程 · 父子课程关联](./coach-flow.md#父子课程关联)。
