# IM 频道

入口：设置 → **IM 频道**

在 Telegram、钉钉、飞书或企业微信里与 AI 教练对话，**进度与 Web 共用**——终端上学到一半，手机上可以继续，教练记得同一段对话。

<div class="docs-callout">

<strong>仅自托管可用</strong>：在线 Demo 未开放 IM Gateway（长连接与回调无法在共享演示环境运行）。需 <a href="./self-host.md">Docker 自托管</a> 后配置。

</div>

## 能做什么

| 能力 | 说明 |
|------|------|
| 导航 | 查课程、选节点、看进度，支持自然语言 |
| 教练对话 | 进入节点后，直接发消息提问或作答 |
| 跨端同步 | 与 Web 同一学习角色、同一会话记忆 |
| 内网部署 | Telegram / 钉钉 / 飞书 WebSocket 模式无需公网 |

建课、删课、改知识树请在 **Web** 操作；IM 侧重学习与导航。

## 配置步骤

1. 自托管启动后，打开 **设置 → IM 频道**
2. 开启 **Gateway 总开关**，填写对应平台凭证
3. **保存后重启服务**（环境变量与 Gateway 需重新加载）
4. 在 IM **单聊**中发送绑定指令，将机器人绑定到你的学习角色

### 绑定角色

在 IM 中发送（任选其一）：

- `绑定 角色名` — 绑定到已有学习角色
- `绑定 XXXXXX` — 使用 Web 设置页显示的 6 位绑定码

绑定成功后，该 IM 账号与此角色的课程、进度、会话共用。

### 支持的平台

| 平台 | 模式 | 公网要求 |
|------|------|----------|
| Telegram | Long Polling | 出站网络即可 |
| 钉钉 | Stream | 内网可用 |
| 飞书 | WebSocket（默认）或 Webhook | Webhook 需 HTTPS |
| 企业微信 | 回调 | 需 HTTPS 公网回调 |

各平台凭证见 [环境变量 · IM Gateway](../reference/env.md#im-gateway)，安装与启动方式见 [自托管部署](./self-host.md)。

## 怎么说

模糊说法先走**零 token 规则**；未命中时再用模型解析。已有进行中的节点会话时，普通消息会**直接进入教练对话**，不会被导航命令打断。

### 自然语言示例

| 你想… | 示例说法 |
|--------|----------|
| 看课表 | 我的课程、有哪些课 |
| 进入某门课 | 学 Go 并发、学习 1 |
| 选节点 | 节点 1、第一个节点 |
| 续上次进度 | 接着学、继续 |
| 看完成情况 | 进度 |
| 下一节点 | 下一节（须当前节点已点亮） |

### 精确命令

`课程`、`学习`、`节点`、`继续`、`进度`、`下一节`、`帮助`

### 教练对话中

进入节点学习后：

- 直接发送问题或练习答案，无需加「节点」前缀
- 与 Web 教练相同：可说「开始练习」「不懂，回讲解」「换一题」「已经掌握，下一节」等（详见 [教练流程](./coach-flow.md)）

**下一节**：仅当当前节点已 `completed`；未完成时会提示先完成练习或申请掌握。
