# 为什么是 Regulus

用大模型聊天当然也能学习，但对话很容易越聊越散：不知道范围有多大，也不知道自己是否真的掌握。Regulus 想解决的不是「让 AI 多讲一点」，而是让一次学习有起点、有练习、有结果。

## 和普通 AI 对话有什么不同

1. **有边界的知识地图，不是无限聊天**
2. **会追着你练完并点亮的教练，不是讲完就走的老师**
3. **越学越懂你——讲解按你的背景裁剪**

每次只学地图上的一个小知识点。听完讲解后做练习，通过后这个知识点会标记为已完成；学得越多，系统越能避开你已经会的内容。

## 为什么没有照搬其他学习产品

Regulus 借鉴了两个优秀的开源项目，但选择了更适合碎片时间的路线：

| 项目 | 借鉴了什么 | Regulus 的选择 |
|------|------------|----------------|
| [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) | 结构化呈现、多 Agent | 课堂节奏偏整块时间，碎片难持续 |
| [DeepTutor](https://github.com/HKUDS/DeepTutor) | 练习生成、RAG 思路 | Embedding / 搜索配置门槛高 |

Regulus 用预定义的学习边界代替复杂知识库配置，希望只用一个模型 Key，就能完成一次讲解、练习、反馈和进度记录。

## 选择适合你的使用方式

- **先体验**：打开 Cloud Demo，无需先准备 Key
- **想保留数据**：选择自托管，学习进度和笔记保存在本机 SQLite
- **想理解教学设计**：继续阅读 [教学模式](./teaching-model.md)
