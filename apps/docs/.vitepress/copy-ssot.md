# 文案维护口径

本文件仅供维护文档时使用，不会发布为用户页面。修改 README、文档首页或产品介绍前，先更新这里，再同步到对应页面。

## 一句话定位

在碎片时间完成：讲解 → 练习 → 反馈 → 点亮 → 沉淀为可带走的知识。

## Key 表述

- **在线 Demo**：无需先备 Key（平台额度；用尽后可填写自己的 Key）
- **自托管 / 长期使用**：一个 OpenAI 兼容 Key 即可

## 差异化

1. 有边界的知识地图，不是无限聊天
2. 会追着你练完并点亮的教练，不是讲完就走的老师
3. 越学越懂你——讲解按你的背景裁剪

## 部署与隐私

- Cloud 先免费试用；共享试用环境请勿放入敏感内容，额度用尽后可填写自己的 Key
- 自托管时，学习数据保存在本机 SQLite

## 命名

| 用语 | 含义 |
|------|------|
| **今日推荐** | 侧栏已上线捷径（优先行动助手计划；其次可匹配知识缺口；否则按进度） |
| **Agent 主动日推** | 规划中的主动推送能力，不使用「每日推荐」称呼 |
| **划词助教** | 教练页划词解术语/读音；面板称「助教」；不写主线进度；缺口进账本反哺推荐 |

## 用户入口

- 不知从哪开课 → **内置课目录**
- 事情太多、节奏乱 → **行动助手**
- 术语 / 读音听不懂 → **划词助教**（教练页划词）

## 产品原则与用户结果

| 原则 | 用户可感知结果 |
|------|----------------|
| 教练不是老师 | 一次一节点；讲 → 练 → 批 → 点亮 |
| 15 分钟叙事单位 | 碎片时间可完成一次可测量进步（非系统计时器） |
| 边界 > 知识库 | 有框的地图；不必先配 RAG |
| 越学越懂你 | 全局画像 + 按课摘要裁剪讲解 |
| 学完可带走 | Skill / Domain / Obsidian；进度跨 Web·IM（仅自托管） |
