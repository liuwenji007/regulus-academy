## 核心项目

### 项目一：阿窝睡了 — 情绪陪伴 AI 产品

**角色：** 创始人 / 独立开发者（产品设计 + 全栈开发）

一款睡前情绪整理工具，核心设计"先说话再复盘"——用户在情绪混乱时打开，一键进入对话倾诉，AI 引导拆解与情绪外化，聊完后输出一个可执行的微行动，获得"今天到这里也可以"的情绪许可感。

**产品设计：**
- 流程设计——首页（选填）→ 聊天（无前置门槛）→ 复盘（便签纸风格视觉）→ 微行动输出 → 存档至树洞/枝头/暂留，形成完整的情绪处理闭环
- 语气体系——定义了一套"温柔、慢速、低压、非评判"的 AI 语气规范，禁用诊断式表达（如"你这是焦虑"）和鸡汤式鼓励（如"振作起来"），并以阳光值（growth_score）五维度评分衡量每次陪伴的效果
- 逻辑闭环——不依赖"profile 画像"设计，所有个性化通过 recall_memory 在对话中自然获取，降低用户信任建立门槛

**当前状态：** 已完成设计与核心开发，等待备案审核上线。产品从品牌体系（主色调/视觉母题/文案规范）到技术链路已全部就绪。

---

### 项目二：Regulus Academy — AI 私教平台

**角色：** 创始人 / 独立开发者（全栈）

一款碎片化学习的 AI 私教产品。用户输入想学的主题，系统自动拆解为知识点模块，以"讲解 → 练习 → 批改 → 点亮"的闭环流程带用户完成一次完整学习。

- 对话状态机设计——五个阶段（explain → exercise → grade → review → completed）的状态流转控制，不同教学阶段使用不同的模型温度参数（结构化阶段 0.2，创意阶段 0.6-0.7）
- Prompt 模块化——将系统提示词拆分为 core（核心约束）+ phase_*（阶段专用），降低修改对全局的影响
- 可观测性——接入 Langfuse OTel 追踪对话链路与阶段转换
- 在线 Demo 可用，GitHub 开源，已收到首批用户反馈，有开发者基于项目进行二次开发

**当前状态：** v0.1.0 公开试用，支持云 Demo 与 Docker 自托管。

---

### 项目三：Agent-opt — AI 评测框架

**角色：** 独立开发者

一套面向 AI Agent 的评测工具，解决"如何系统性评估 Agent 的对话质量"这一核心难题。

- Flow 评测模式——通过与 Agent 真实 API 交互来模拟用户走完整对话流程，记录每一步的 phase 切换、token 消耗与响应质量
- 多维度评分——结合 LCS 序列比对与 LLM-as-Judge，从任务完成度、对话连贯性、阶段合规性、回复质量、异常处理五个维度评分
- 自优化闭环——根据评测结果自动生成改进变体，跑 A/B 对比后选最佳写回，实现 Prompt 的持续迭代
